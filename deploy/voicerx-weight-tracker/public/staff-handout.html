🚀 Set up & daily use

1
Add a patient: tap ＋, enter name (DOB/MRN optional), starting weight, and weekly goals.
2
Log a week: open the patient → Diary tab → fill meals, water, sleep, movement. Use ‹ › to change weeks.
3
Review: the Summary tab shows the weekly tally, goal hits, and weight/movement trends.
4
Chart it: tap 🖨 to print/PDF the week into AtlasMD.

📥 Patient logs & backups

  • 📤
    Patient taps Send my diary to the clinic in their app → emails/sends you a file.
  • ⬇
    In the Tracker, tap Import a patient's shared week and pick that file — it merges into their record (no duplicates).
  • 💾
    Back up all data after each clinic day — keep the file somewhere safe.
  • ↺
    Restore from a backup to move to a new device or recover.
Patient data lives only on this device. There is no cloud copy and no login — keep the device passcode-locked, don't hand it to patients, and back up regularly. This tool supports care; it is not the medical record (AtlasMD is).
