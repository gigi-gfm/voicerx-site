# VoiceRx Booklet — Photos

This folder holds the artwork for the 10-page VoiceRx booklet
(`../index.html`). Each page that shows a photo currently uses a **branded
placeholder** (the dashed “replace with photo” camera card) so the booklet
renders and prints correctly before the real photography is dropped in.

## How the placeholders work

- The placeholders are lightweight SVG files named `pNN-<slot>.jpg.svg`.
- The booklet references them directly, so the layout is final — only the
  picture inside each frame needs to change.
- The `.jpg.svg` naming is intentional: it documents the **target real photo**
  (`pNN-<slot>.jpg`) while keeping a working SVG today.

## Swapping in a real photo

Drop your real photo `pNN-<slot>.jpg` into this folder, then in
`../index.html` change that one `src` from `images/pNN-<slot>.jpg.svg` to
`images/pNN-<slot>.jpg`. That's the whole change — the frame, sizing, and
caption stay exactly as they are.

Keep the **aspect ratio** close to the target below; the frames use
`object-fit: cover`, so faces and key subjects should sit near the center.

## Style notes

- **Palette:** the booklet is navy (`#1e3a8a → #1e40af`) with orange accents
  (`#f97316 → #fb923c`). Photos with warm skin tones and a touch of orange/amber
  sit naturally against it; cool/clinical blues also work on dark pages.
- **People first.** Favor real faces and hands over abstract tech imagery —
  VoiceRx is about giving the clinician their attention (and evening) back.
- **Privacy:** if real patients appear, obtain consent and avoid any visible
  PHI on screens. Use staged demo data for anything showing the app.
- **Resolution:** aim for at least the pixel sizes shown on each placeholder
  (cover/landscape ≈ 1600×1000, portraits ≈ 1200×1400) so it prints crisp on A4.

## Regenerating the placeholders

The placeholders were generated by the `gen` loop in the booklet commit; you
can recreate or tweak them with any SVG editor. They carry no real content and
are safe to delete once every slot has a real photo.
