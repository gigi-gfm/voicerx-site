# GFM Booklet — Photos

Drop your real photos into this `images/` folder using the **exact filenames**
below. The booklet picks them up automatically — each photo replaces its
placeholder frame as soon as the file exists. No code editing needed.

Use JPGs (or PNGs renamed to `.jpg`). Landscape shots work best for the wide
frames; a vertical portrait is ideal for Dr. Tess and team headshots.

| Filename                  | Where it appears        | Best shot                                   |
|---------------------------|-------------------------|---------------------------------------------|
| `cover-office.jpg`        | Cover (pg 1)            | Warm, inviting office exterior or front desk |
| `dr-tess.jpg`             | Meet Dr. Tess (pg 2)    | Vertical portrait of Dr. Tess                |
| `dpc-visit.jpg`           | Membership (pg 4)       | Dr. Tess with a patient in an exam room      |
| `weight-management.jpg`   | Weight Mgmt (pg 5)      | Consultation / healthy-lifestyle image       |
| `corelift.jpg`            | CoreLift (pg 6)         | EMSELLA device / treatment room              |
| `team-1.jpg`              | Team (pg 9)             | Dr. Tess headshot                            |
| `team-2.jpg`              | Team (pg 9)             | Gigi (Practice Manager) headshot             |
| `team-3.jpg`              | Team (pg 9)             | Jacenta (Assistant Manager) headshot         |
| `team-4.jpg`              | Team (pg 9)             | Hooch (Comfort Specialist) photo             |
| `office-1.jpg`            | Office gallery (pg 9)   | Waiting room / reception                     |
| `office-2.jpg`            | Office gallery (pg 9)   | Exam room                                    |

## To produce the final PDF

1. Open `gfm-booklet/index.html` in Chrome.
2. Click **Print / Save as PDF** (top right).
3. In the print dialog: paper **Letter**, margins **None**, and turn ON
   **Background graphics**. Save.

You'll get a 10-page, print-ready PDF booklet.
