## View it

Open `index.html` in any browser. It’s a single self-contained file (web
fonts + local images, no build step).

## Make a PDF

Open `index.html` and click **Print / Save PDF** (top right), or use the
browser’s Print dialog:

- **Destination:** Save as PDF
- **Paper:** A4, **Portrait**
- **Margins:** None / Default
- **Background graphics:** ON (so the navy pages and accents print)

Each section is sized to one A4 page, so you get exactly 10 pages.
