# Sample patient data

These are example **Trim patient export files** — the kind of file a patient
produces when they tap **Export** in the Trim app. Use them to try out the
clinic tracker without needing real patient data.

## Two ways to load them

**Quick demo (all at once):** open the clinic tracker (`clinic/index.html`),
click **Restore**, and pick `_demo-roster.json`. That loads all five sample
patients instantly. (Restore replaces your current roster.)

**One at a time (simulates the real workflow):** click **Import patient file**
and pick any of the individual files below. This is exactly what you'll do with
a file a real patient sends you.

## The samples (chosen to show each status)

| File | Patient | Shows |
|------|---------|-------|
| `jane-doe.json` | Jane Doe (kg) | **On track** — steady loss toward goal |
| `priya-patel.json` | Priya Patel (kg) | **Goal reached** |
| `maria-garcia.json` | Maria Garcia (kg) | **Stalled** — weight flat |
| `robert-smith.json` | Robert Smith (lb) | **Off track** — trending away from goal (and shows pounds) |
| `tom-lee.json` | Tom Lee (kg) | **Needs attention** — no weigh-in in 34 days |

All data is fictional. `_demo-roster.json` is a pre-built roster backup
containing all five, for the one-click demo.
